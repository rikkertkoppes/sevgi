# Welcome to Sevgi

Sevgi is a node based 2D graphics editor aimed at lasercutting and cnc applications

It is in a VERY rough state at the moment, it can break suddenly and can get updated at any moment. Nevertheless it does things

Have a look at https://sevgi.vercel.app and play around. Do create issues if you have ideas or find bugs, please mention the version number if you do

# Changelog

## v0.2.4

-   General speedup of grid layouts
-   Added Rectangle and Box nodes in Create
-   Added Count Points node in Modify
-   Added 3.12.12 and 3.4.6.4 Grid nodes in Patterns, also added flip parameter to most grids.
-   Added Cartesian groups and Concat nodes in List
-   Added Simplify Tree node in Tree
-   Added Equal To, Modulo, Sine, Cosine, Tangent, Square Root and Power nodes to Math
-   Improvements for mobile layout, long press nodes to be able to delete them, add fullscreen toggle
-   Added icons for everything
